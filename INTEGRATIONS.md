# Lumi MAX integrations

This local hub is designed to grow through official integrations.

- YouTube: use Google's OAuth and YouTube APIs where the account and app permissions allow.
- Instagram: use Meta's official login/API capabilities where available.
- OpenAI: use the Responses API for new AI integrations.
- Voice: the current build uses browser speech; a future realtime voice backend can replace it.
- Character: the current artwork is an original avatar layer. A true Live2D/3D character needs a separately rigged original model.

Never put a social-media password into this app. Use official authorization flows.
