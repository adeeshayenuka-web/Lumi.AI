# Lumi MAX ULTRA PRO MAX — 3D + Voice Upgrade

This upgrade adds a local, dependency-free 3D-style avatar renderer and expanded customization.

## 3D avatar
- Full-body volumetric-style 3D scene rendered in a browser canvas.
- Automatic blinking.
- Talking mouth animation while speech synthesis is active.
- Idle breathing/bobbing and expression changes.
- Drag to rotate the character.
- Scroll to zoom in the Character Lab.
- Separate 3D avatar views for Chat, Voice Room, and Character Lab.

## Character customization
- Name and personality.
- Hair style: long, short, twin-tail, bob.
- Hair color.
- Eye color.
- Outfit style: hoodie, jacket, casual, uniform.
- Outfit color.
- Skin tone.
- Accessory: cat clip, star clip, bow, none.
- Accent color.
- Avatar scale.
- Settings persist in browser localStorage.

## Anime voice packs
- Lumi Cute
- Sparkle
- Soft
- Bright
- Storyteller
- Clear

Voice packs are browser speech-synthesis presets. They change pitch/speed and select the available browser voice. They are not cloned voices and do not claim to reproduce a real person.

## Offline behavior
The avatar renderer, blinking, animation, customization, and browser speech synthesis are local. Online AI chat still requires the configured OpenAI API connection; the existing offline fallback remains available.
