# Lumi Ultimate Companion v3

A polished local AI companion dashboard with:
- AI chat through the OpenAI Responses API
- local memory
- browser voice input/output
- animated character stage
- personality/name/theme controls
- movie/video room for media you are allowed to play
- Tic-Tac-Toe and reaction game
- notes and quick actions
- responsive desktop/mobile layout

## Windows setup
1. Install Node.js 20+.
2. Open this folder in CMD.
3. Run `npm install`
4. Copy `.env.example` to `.env`
5. Put your OpenAI API key into `.env`
6. Run `npm start`
7. Open http://localhost:3000

Keep the CMD window open while using the app.

The character artwork is an original fictional visual used as the current avatar artwork. The app's browser animation creates motion around it; a future Live2D/3D rig can replace the artwork without changing the AI backend.

The media room is for local/authorized media only and does not bypass DRM, paywalls, or access controls.
